SimNest Gateway

Runs on the Android phone at home that holds your SIM. It takes over that SIM's incoming calls, outgoing calls and texts, and passes them, encrypted, to your and your family's iPhones.

Download from GitHub Download from Gitee Source code

Both carry the same APK. Use Gitee if GitHub is slow where you are.

The gateway works together with SimNest for iPhone, which is in an invite-only TestFlight beta. Without the iPhone app the gateway can't be paired.

What you need

  • An arm64 Android phone running Android 12 or later, with the SIM you want to use. A spare phone dedicated to the job is best.
  • Keep it plugged in and on your home Wi-Fi.
  • Turn on Wireless debugging in Developer options during setup. The gateway uses it to start an audio service on the phone that carries call audio; without it, calls have no sound.

Permissions it asks for

The gateway needs more than an ordinary app. Each one is explained in the app, and you grant it in the system dialog.

  • Phone, call log, make calls, SMS, contacts: forward calls and texts, show the caller's number on your iPhone, call out through the gateway.
  • Default phone app and default SMS app: know when the other side answers; stop the system from asking to confirm every outgoing text.
  • Wireless debugging: start the audio service on the phone.
  • Modify secure settings: only to turn Wireless debugging back on after a restart or Wi-Fi change.
  • Start at boot, foreground service: the gateway comes back by itself after a restart, always visible in the notification shade, and you can stop it any time.

The gateway never places calls on its own. It calls out and sends texts only for the owner and the family the owner has allowed.

Updates

The official APK checks GitHub and Gitee for new releases, and before installing one checks that the package name, version and signature match what's installed. By default it just tells you; you can turn on automatic updates under About.

Check the APK

Each release's notes give the APK's SHA-256. To check it on a computer:

shasum -a 256 simnest-gateway-*.apk

Build it yourself

The source is on GitHub; the readme explains how to build. A build of your own doesn't include the address of SimNest's core service, so it installs and shows every screen but can't pair.
