SimNest 閘道

裝在家裡那支插著 SIM 卡的 Android 手機上。它接管這張卡的來電、撥出和簡訊，加密後轉給你和家人的 iPhone。

從 GitHub 下載 從 Gitee 下載 原始碼

兩處是同一個安裝檔。GitHub 連線慢的話用 Gitee。

閘道要搭配 SimNest iPhone App 使用，iPhone App 目前透過 TestFlight 邀請內測。沒有 iPhone App，閘道裝好後無法配對。

需要什麼

  • 一支 Android 12 以上、arm64 的 Android 手機，插著你要用的 SIM 卡。建議用閒置手機專門當閘道。
  • 手機長期接上電源、連著家裡的 Wi-Fi。
  • 第一次設定時開啟開發人員選項裡的「無線偵錯」。閘道用它在本機啟動一個音訊服務，把通話聲音接出來，這是通話有聲音的前提。

驗證過的機型

手機系統狀態
Redmi Note 11 5GAndroid 13（HyperOS 1.0）維護者日常使用
華為 Mate 40 RSHarmonyOS 4.2部分可用：沒有無線偵錯，手機重新開機後要接一次電腦才有聲音

其他機型還沒驗證過。Android 品牌和系統改動太多，我們沒辦法逐一測試，這也是閘道開源的原因之一：你的手機能用、不能用，都歡迎在 Issues 告訴我們。儲存庫裡有一份給貢獻者的適配和取證說明。

它在手機上要哪些權限

閘道要的權限比一般 App 多。每一項都在 App 裡寫明用途，由你在系統對話框裡允許。

  • 電話、通話記錄、撥打電話、簡訊、通訊錄：轉接來電和簡訊，讓 iPhone 看到來電號碼，透過閘道撥出。
  • 預設電話 App、預設簡訊 App：知道對方什麼時候接聽；避免系統每傳一則簡訊都跳出確認。
  • 無線偵錯：在本機啟動音訊服務。
  • 修改安全設定：只用來在重新開機或換 Wi-Fi 後重新開啟無線偵錯。
  • 開機自動啟動、前景服務：手機重新開機後閘道自己恢復，通知欄一直看得到它在執行，可以隨時關閉。

閘道不會自己撥號。它替 iPhone 撥出和傳簡訊時，只聽主人和主人授權的家人。

更新

官方安裝檔會查 GitHub 和 Gitee 上的最新版本，下載後核對套件名稱、版本和簽章（必須和已安裝的一致）再安裝。預設只提示你，也可以在「關於」裡開啟自動更新。

核對安裝檔

每個版本的發布說明裡寫著安裝檔的 SHA-256。下載後可以在電腦上核對：

shasum -a 256 simnest-gateway-*.apk

自己編譯

原始碼在 GitHub，編譯方法見儲存庫說明。自己編譯的安裝檔裡沒有 SimNest 核心服務的位址，裝好後介面都在，但無法配對。
