SimNest 网关

装在家里那台插着 SIM 卡的安卓手机上。它接管这张卡的来电、拨出和短信，加密后转给你和家人的 iPhone。

从 GitHub 下载 从 Gitee 下载 看源代码

两处是同一个安装包。国内访问 GitHub 慢的话用 Gitee。

网关要配合 SimNest iPhone App 使用，iPhone App 目前经 TestFlight 邀请内测。没有 iPhone App，网关装上后不能配对。

需要什么

  • 一台 Android 12 及以上、arm64 的安卓手机，插着你要用的 SIM 卡。建议用闲置手机专门做网关。
  • 手机长期插电、连着家里的 Wi-Fi。
  • 第一次配置时打开开发者选项里的“无线调试”。网关用它在本机启动一个音频服务，把通话声音接出来，这是通话有声音的前提。

验证过的机型

手机系统状态
Redmi Note 11 5GAndroid 13（HyperOS 1.0）维护者日常在用
华为 Mate 40 RSHarmonyOS 4.2部分可用：没有无线调试，手机重启后要连一次电脑才有声音

其他机型还没验证过。安卓品牌和系统改动太多，我们没法逐一去试，这也是网关开源的原因之一：你的手机能用、不能用，都欢迎在 Issues 里告诉我们。仓库里有一份给贡献者的适配和取证说明。

它在手机上要哪些权限

网关要的权限比普通应用多。每一项都在应用里写明用途，由你在系统弹窗里允许。

  • 电话、通话记录、拨打电话、短信、通讯录：转接来电和短信，让 iPhone 看到来电号码，经网关拨出。
  • 默认电话应用、默认短信应用：知道对方什么时候接听；避免系统每发一条短信都弹确认框。
  • 无线调试：在本机启动音频服务。
  • 修改安全设置：只用来在重启或换 Wi-Fi 后重新打开无线调试。
  • 开机自启、前台服务：手机重启后网关自己恢复，通知栏一直看得到它在运行，可以随时关闭。

网关不会自己拨号。它替 iPhone 拨出和发短信时，只听主人和主人授权的家人。

更新

官方安装包会查 GitHub 和 Gitee 上的最新版本，下载后核对包名、版本和签名（必须和已装的一致）再安装。默认只提示你，也可以在“关于”里打开自动更新。

核对安装包

每个版本的发布说明里写着安装包的 SHA-256。下载后可以在电脑上核对：

shasum -a 256 simnest-gateway-*.apk

自己编译

源码在 GitHub，编译方法见仓库说明。自己编译的包里没有 SimNest 核心服务的地址，装上后界面都在，但不能配对。
